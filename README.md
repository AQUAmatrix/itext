iText
Aplicação para assinatura de documentos PDF utilizando a biblioteca iText.

Descrição
Este projeto contém uma componente que processa documentos PDF localizados numa pasta e executa a respetiva assinatura digital e um componente para distribuição dos ficheiros via SMTP
